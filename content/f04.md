## What an API is

Your program runs on your machine. Claude runs on Anthropic's computers. An **API** is the
arrangement that lets one talk to the other.

::: jargon API
Application Programming Interface. A way for one program to ask another program to do something.

The useful mental picture is ordering at a counter. You do not go into the kitchen. There is a menu
of things you may ask for, a fixed way of asking, and something comes back. The API is the counter,
the menu, and the rules about how to order.
:::

For our purposes, calling an API means: your program sends some text over the internet, another
computer does something with it, and sends text back. That is all that is happening in this module.

## JSON: the format things travel in

Programs on different machines, possibly written in different languages, need an agreed way to write
information down. The agreed way is **JSON**.

Here is some:

```json
{
  "role": "user",
  "content": "What is the capital of Norway?"
}
```

You have seen this before. That is a dictionary — curly braces, keys, values. And this:

```json
[
  {"role": "user", "content": "Hello"},
  {"role": "assistant", "content": "Hi there"}
]
```

is a list of dictionaries, exactly as in the last module.

::: jargon JSON
JavaScript Object Notation. A text format for structured information, built from the same pieces you
already know: labelled collections (like dictionaries), ordered collections (like lists), text,
numbers, and true/false.

You do not have to write JSON by hand here. You write Python dictionaries and lists; the library
converts them. It matters only because when you look at what actually crossed the wire — which you
will do constantly from Module 1 onwards — this is what you are looking at.
:::

## Getting a key

To use the API you need an **API key**: a long secret string that identifies your account and gets
you billed.

1. Go to [console.anthropic.com](https://console.anthropic.com) and make an account.
2. Add a small amount of credit. **Five dollars is more than enough for this entire course** —
   the exercises here cost pennies.
3. Find **API keys** in the settings and create one. It looks like `sk-ant-` followed by a long
   string.
4. **Copy it now.** You are shown it once.

::: warn Treat the key like a password
Anyone with your key can spend your money.

**Never put it directly in your code.** Not even temporarily, not even in a file you think is
private. The reason is boring and universal: code gets copied, pasted into chats, shared for help,
and committed to GitHub — and keys leaked this way are found by automated scanners within minutes.

We are about to do it the correct way, and the correct way is barely more work.
:::

## Storing the key properly

We put the key in the **environment** — a set of named values your programs can read, which live
outside your code.

**Mac / Linux**, in the terminal:

```bash
export ANTHROPIC_API_KEY="sk-ant-paste-yours-here"
```

**Windows PowerShell**:

```powershell
$env:ANTHROPIC_API_KEY="sk-ant-paste-yours-here"
```

Check it worked:

```bash
echo $ANTHROPIC_API_KEY
```

::: try This only lasts until you close the terminal
That is deliberate — nothing was written to disk. When you open a new terminal you set it again.

To make it permanent on Mac/Linux, add the same `export` line to the file `~/.zshrc` (or
`~/.bashrc`), then open a new terminal. On Windows, search for "environment variables" in the Start
menu and add it there.
:::

## Your first call

Create `first_call.py`:

```python title=first_call.py
import anthropic

# Creates the object that talks to the API.
# It finds your key in the environment automatically — you never type it here.
client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-opus-5",
    max_tokens=1000,
    messages=[
        {"role": "user", "content": "What is the capital of Norway? Answer in one sentence."}
    ],
)

print(response.content[0].text)
```

Run it:

```bash
python3 first_call.py
```

You should get a sentence about Oslo. **You have just written a program that talks to an AI model.**

### What every line does

**`import anthropic`** — makes the library available. Like `print`, but it came from outside.

**`client = anthropic.Anthropic()`** — creates the thing that does the talking, and stores it under
the name `client`. It looks for `ANTHROPIC_API_KEY` in the environment by itself.

**`client.messages.create(...)`** — the actual call. The dot means "the `messages` part of `client`,
and the `create` action of that". Everything inside the brackets is what you are asking for:

- **`model="claude-opus-5"`** — which model. Different models cost different amounts and vary in
  capability.
- **`max_tokens=1000`** — the most tokens the model may write back. A safety limit: it stops a
  runaway reply costing you a fortune.
- **`messages=[...]`** — the conversation. A list of dictionaries, exactly the shape from Module F3.
  `"role": "user"` means this came from you.

**`response.content[0].text`** — digging the text out of the reply, which we will look at now.

## What comes back

The reply is not a piece of text. It is a structured object with several parts, and understanding
its shape now will save you real confusion in Module 1.

```python title=inspect_reply.py
import anthropic

client = anthropic.Anthropic()
response = client.messages.create(
    model="claude-opus-5",
    max_tokens=1000,
    messages=[{"role": "user", "content": "Name three Norwegian cities."}],
)

print("stop reason:", response.stop_reason)
print("blocks:     ", len(response.content))
print("block type: ", response.content[0].type)
print("text:       ", response.content[0].text)
print("tokens in:  ", response.usage.input_tokens)
print("tokens out: ", response.usage.output_tokens)
```

**`response.content` is a list**, which is why you write `content[0]` to get the first item. Right
now there is only one thing in it. In Module 1 there will be several, and one of them will be the
model asking you to run a tool — so getting used to it being a list is worth doing today.

**`response.stop_reason`** tells you why it stopped. `end_turn` means it finished naturally.
`max_tokens` means it hit your limit mid-sentence — the answer is cut off, and treating that as a
complete reply is a real bug you will meet again.

**`response.usage`** is what you were charged for.

## What that cost

Prices are per million tokens and change, so check the current rates on Anthropic's pricing page and
put them in one place:

```python title=cost.py
# Per million tokens. Check current published rates before trusting these.
PRICE_IN = 5.00
PRICE_OUT = 25.00

def cost_of(usage):
    """Return the dollar cost of one call."""
    return (usage.input_tokens * PRICE_IN
            + usage.output_tokens * PRICE_OUT) / 1_000_000

print("this call cost $" + str(round(cost_of(response.usage), 6)))
```

A short question like the one above costs a tiny fraction of a cent. Two things to notice now,
because both become important:

**Output costs several times more than input** per token.

**Input grows as a conversation goes on.** Every turn re-sends everything before it. In Module 12
you will find this is the dominant cost in nearly every agent, and that it grows with the *square*
of the number of turns.

::: deeper Having a conversation, and seeing statelessness for yourself
The model has no memory. To have a back-and-forth, you re-send the whole conversation each time —
which you can watch happening:

```python
messages = [{"role": "user", "content": "My name is Ada."}]

first = client.messages.create(model="claude-opus-5", max_tokens=1000, messages=messages)
print(first.content[0].text)

# Add the reply, then your follow-up, then send the WHOLE list again.
messages.append({"role": "assistant", "content": first.content[0].text})
messages.append({"role": "user", "content": "What is my name?"})

second = client.messages.create(model="claude-opus-5", max_tokens=1000, messages=messages)
print(second.content[0].text)
print("input tokens, call 1:", first.usage.input_tokens)
print("input tokens, call 2:", second.usage.input_tokens)
```

It knows your name on the second call — because you sent it again. Delete the two `append` lines and
it will not.

Watch the two input-token numbers. The second is larger, and it will keep growing every turn. That
is the whole of Module 3 and most of Module 12, visible in a six-line program.
:::

::: warn Things that commonly go wrong here
**`AuthenticationError`** — the key is not set, or the terminal running the script is not the one you
set it in. Run `echo $ANTHROPIC_API_KEY` in the *same* window.

**`ModuleNotFoundError: No module named 'anthropic'`** — the library is not installed, or is
installed for a different Python. Try `python3 -m pip install anthropic`.

**`RateLimitError`** — too many requests too quickly. Wait a moment. Module 12 is about handling this
properly, and doing it badly is how a small blip becomes an outage.

**A bill larger than you expected** — check `max_tokens`, and check you are not looping. Set a
spending limit in the console; it is one click and worth doing today.
:::

## What you now know

- An **API** lets your program ask another computer to do something.
- **JSON** is a text format built from the lists and dictionaries you already know.
- An **API key** identifies and bills you. It lives in the environment, never in your code.
- `client.messages.create(...)` sends a conversation and returns a structured reply.
- **`response.content` is a list**; `stop_reason` says why it stopped; `usage` is what you paid.
- Conversations work by **re-sending everything**, and that is where the cost lives.

That is the foundation. Next: Module 1, where you take this single call and put it in a loop — and
that loop is an AI agent.
